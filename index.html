Disability is normalized.
特別から、日常へ。

Bias は、障害を「特別なもの」として切り離すのではなく、 日常の中にあるひとつの揺らぎとして捉え直すプロジェクトです。 思想（BIAS CORE）、アパレル（BIAS APPAREL）、体験（GLEAM）の 3つのラインを通して、社会の“見え方”を静かにずらしていきます。

About

Bias Project

家族に障害がいること、福祉の現場で働くことを通して、 「障害そのもの」よりも「社会のまなざし」に違和感を覚えたことが Bias の出発点になりました。

正しさだけでは偏見はほどけない。 光、線、言葉、服、場づくりを通して、 いまある福祉のイメージを少しだけズラす。 そのための小さな実験を積み重ねていくプロジェクトです。

Instagram @us_bias
Lines

3つのライン

BIAS CORE
思想・言葉

詩、エッセイ、ZINEなどを通して、 「障害」「ふつう」「日常」の見方を問い直すライン。 言葉とビジュアルで、考え方の土台を少しだけ揺らします。

→ noteで読む
BIAS APPAREL
アパレル

「特別ではなく日常にある障害」という視点を、 毎日着られる服に落とし込むライン。 ロゴ、文字、光のモチーフを使ったTシャツなどを展開します。

→ SUZURIで見る
GLEAM
体験・イベント

光と音を使った体験イベント。 障害のある人／ない人、福祉とカルチャーが ゆるやかにまざる夜をデザインします。

→ Gleamについて読む
